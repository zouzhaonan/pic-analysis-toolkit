Usage:
  pic all --out-dir <dir> --sample-sheet <tsv> --raw-fastq-dir <dir> [--run-name <name>]

Overview:
  Run the full analysis end-to-end in one command:
  mapping -> deseq2 -> enrich -> report (HTML)

  For each genome found in the sample sheet, deseq2 and enrich are run
  automatically. This subcommand is intentionally simple and takes only the
  options below. If you need to tune parameters (e.g. --fdr, --methods),
  run `pic deseq2` / `pic enrich` individually instead.

Required options:
  --out-dir <dir>            Output directory
  --sample-sheet <tsv>       Sample sheet TSV (same format as `pic mapping`)
                             Example:
                             - - - - - - - - - - - - - - - - - - - - - - - - -
                               fastq_prefix  genome  barcode  sample   group
                               brain         mm10    AGGATC   brain_1  brain
                               brain         mm10    TCGAAG   brain_2  brain
                               ovary         mm10    TCCTTC   ovary_1  ovary
                               ovary         mm10    TGTCTG   ovary_2  ovary
                             - - - - - - - - - - - - - - - - - - - - - - - - -
  --raw-fastq-dir <dir>      Directory containing raw paired FASTQ files (R1 & R2)
                             * Not needed when --demux-fastq-dir is given

Optional options:
  --run-name <name>          Run name suffix for output files (default: random 8 chars)
  --demux-fastq-dir <dir>    Use already-demultiplexed/classified FASTQ (skips demux).
                             Each sample is read from <dir>/<sample>.fastq.gz
  --no-report                Skip the final HTML report step
  --hisat2-score-min <spec>  hisat2 --score-min (default: L,0,-1)
                             pic defaults to L,0,-1 because PIC Read2 starts with
                             the RT primer's random hexamer (non-templated by
                             design); hisat2's own default L,0,-0.2 cannot afford
                             to soft-clip it. Pass L,0,-0.2 to restore it.
  --hisat2-very-sensitive    Add --very-sensitive to hisat2 (default: off)
                             Not recommended: same yield as the default
                             --score-min at ~4x the runtime.

Output layout:
  <out-dir>/                 mapping artifacts (counts, bam, bw ...)
  <out-dir>/summary/         summary tables (mapping_sum, deftable,
                             aggregate_profile, analysis_params)
  <out-dir>/deseq2/          DESeq2 results (genome encoded in the file names as
                             <run>_<genome>, not in subdirectories)
  <out-dir>/enrich/          ORA/GSEA results (same naming)
  <out-dir>/report_<run>_<genome>.html  interactive HTML report per genome

Examples:
  pic all \
    --sample-sheet /path/sample.tsv \
    --raw-fastq-dir /path/raw_fastq \
    --out-dir /path/out \
    --run-name test
