Usage:
  pic plot-expression --count <path> --deftable <path> --gene-list <path> --out <path>

Overview:
  Generate group-wise violin plots for normalized expression of selected genes.

Required options:
  --count <path>         deseq2 output normalizedCountTable_*.csv
  --deftable <path>      Deftable TSV used for deseq2 input
  --gene-list <path>     Text file with one ID/gene name per line
  --out <path>           Output PDF path

Example:
  pic plot-expression \
    --count /path/to/normalizedCountTable.csv \
    --deftable /path/to/deftable.tsv \
    --gene-list /path/to/genes.txt \
    --out /path/to/plot.pdf
