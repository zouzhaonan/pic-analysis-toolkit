Usage:
  pic enrich --stats <path> --genome <name> --out-dir <dir> --deg-clusters <path> [options]
  pic enrich --prepare-libs --genome <name> [--categories <csv>]

Overview:
  Run ORA/GSEA enrichment analysis from DESeq2 stats.

Required options:
  --stats <path>           DESeq2 stats CSV
  --genome <name>          Genome name in <lib_dir>/register/genome_enrichment_map.tsv
  --out-dir <dir>          Output directory
  --deg-clusters <path>    deseq2 output: DEG/DEGCluster/DEGCluster_gene_for_ora_*.csv

Optional options:
  --project-name <name>    Output suffix (default: auto from --stats filename)
  --threads <n>            Number of parallel threads (default: 8)
  --methods <csv>          Methods to run (comma-separated)
                           default: GO_BP,KEGG,REACTOME,WIKIPATHWAYS,HDO,HPO,MPO
                           choices: defaults + GO_CC, GO_MF

Library preparation:
  --prepare-libs --genome <name>    Prepare local enrichment libraries for new genome assemblies


ID mapping behavior:
  - Libraries are gene symbol–based.
  - If genome x category is unavailable mapped human ortholog symbols are used.

Examples:
  pic enrich \
    --stats /path/to/stats_mm10.csv \
    --genome mm10 \
    --out-dir /path/to/out \
    --deg-clusters /path/to/DEGCluster_gene_for_ora_xxx.csv

  pic enrich --prepare-libs --genome mm10
