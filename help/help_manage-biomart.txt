Usage:
  pic manage-biomart --list-datasets [--source <name>]
  pic manage-biomart --register --genome <name> --dataset <name> [--source <name>]

Overview:
  List and register biomart datasets.

Actions:
  --list-datasets       Show available datasets for the selected source
  --register            Download selected dataset and register into lookup

Required options (for --register):
  --genome <name>       Genome name to register (e.g. mm10, hg38, rn7)
  --dataset <name>      biomart dataset name (e.g. mmusculus_gene_ensembl)

Optional options:
  --source <name>       biomart source (default: ensembl)
                        choices: ensembl, plants, fungi, protists, metazoa

Examples:
  pic manage-biomart --list-datasets
  pic manage-biomart --register --genome rn7 --dataset rnorvegicus_gene_ensembl
