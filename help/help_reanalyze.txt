pic reanalyze — サンプル / group を除いて deseq2・enrich・report を作り直す

概要:
  pic all (mapping) の出力から、指定したサンプル (と group) を除いて DESeq2・enrichment・
  HTML レポートだけを作り直す。mapping はやり直さない。元の出力ディレクトリは書き換えない。
  レポートの各タブでサンプルを除外すると、そのままコピーして使えるこのコマンドが表示される。

使い方:
  pic reanalyze --out-dir <元> --new-out-dir <新>
                [--exclude-samples <s1,s2,...>] [--exclude-groups <g1,g2,...>]
                [--threads <n>]

オプション:
  --out-dir <dir>            元の出力ディレクトリ (pic all / mapping の --out-dir。必須)
  --new-out-dir <dir>        作り直した結果の置き場 (必須)。無いか空のディレクトリで、
                             元の --out-dir の外にあること。
  --exclude-samples <list>   除外するサンプル (カンマ区切り。deftable の sample 名)
  --exclude-groups <list>    group ごと除外する (カンマ区切り。deftable の group 名)
                             (--exclude-samples か --exclude-groups の少なくとも一方が必須)
  --threads <n>              deseq2 / enrich / report に渡すスレッド数 (既定 8)

動き:
  1. 除外を確かめる。次のときは何も作らずに止める (終了コード 1):
     - deftable に無いサンプル / group を指定した
     - あるサンプルの除外で group のサンプルが 0 になる (group ごと外すなら --exclude-groups に入れる)
     - 除外の後に残る group が 2 つ未満 (比較が組めない)
  2. <新> に、元の mapping の出力 (bam・bw・counts・log・demux など) への symlink を置く。
     summary/ は写して、deftable・mapping_sum・aggregate_profile と sample_sheet.tsv から
     除外したサンプルの行を外す (aggregate_profile はサンプルごとの値なので計算し直さない)。
  3. summary/analysis_params.tsv に excluded_samples / excluded_groups / reanalyzed_from を
     記録する (reanalyze の出力をさらに reanalyze すると除外は足されていく)。
     作り直したレポートの Overview の先頭に、何を除外したかが出る。
  4. deseq2 → enrich → report を pic all と同じ順に流す。

出力:
  <新>/deseq2/  <新>/enrich/  <新>/summary/  <新>/report_<run>_<genome>.html

注記:
  - xenograft の出力 (graft/ host/) には対応しない。
  - レポートの表示するコマンドの --out-dir は、レポートを作った計算機での絶対パス。
