pic report — 解析結果から自己完結型 HTML レポートを生成する

概要:
  mapping / deseq2 / enrich の出力ディレクトリを読み取り、1 つの HTML
  レポートを出力する。
  PCA / heatmap / MA / volcano はインタラクティブ (マウス hover でラベル表示)。

使い方:
  pic report --out-dir <dir> [--rin-dir <dir>] [--rin-pc-dir <dir>]
             [--threads <n>] [--mem-gb <gb>]

オプション:
  --out-dir <dir>   mapping/deseq2/enrich を含む出力ベース (必須)。
                    配下の deseq2 stats_*.csv ごとに 1 レポートを生成する。
  --rin-dir <dir>   TapeStation の RIN データセットのフォルダ (任意)。
                    省略時は環境変数 PIC_RIN_DIR を使う。それも無ければ
                    開発元の研究室の Dropbox の場所
                    (~/OkiLab Dropbox/OkiLab_Data/TapeStation/RIN_raw_data) を見る。
                    ほかの環境では --rin-dir か PIC_RIN_DIR で指定する。
                    どれも見つからなければ RNA integrity は出さない (エラーにはしない)。
  --rin-pc-dir <dir>
                    RNA ScreenTape 用ポジティブコントロールのフォルダ (任意)。
                    テープが普通の RNA (assay 名 RNA) のときは毎回 PC を図に重ねる
                    (HS RNA には入れない)。省略時は PIC_RIN_PC_DIR →
                    <rin-dir>/RNA_positive_control → 既定パス/RNA_positive_control。
  --threads <n>     並べる worker の数 (任意。既定 1)。節ごとの組み立て・GSEA/ORA の
                    CSV の読みと図づくり・埋め込みファイルの圧縮を fork で並べる。
                    出力の HTML は --threads によらず 1 バイトも同じ。
  --mem-gb <gb>     worker のメモリの上限 (任意)。worker 1 本 0.5 GB として、本数 × 0.5 が
                    この値を超えないように worker を減らす。省略時は環境変数 PIC_MEM_GB、
                    それも無ければ制限なし。

出力:
  <out-dir>/report_<project>.html   (project = <run>_<genome>)

内容 (タブ構成):
  Overview & downloads  レポート概要 + プロジェクトの全 csv/tsv ファイル一覧
                        (各ファイルは HTML に埋め込み、クリックでダウンロード)
  1. Mapping QC        RNA integrity (RIN データがあるときだけ)・リード分布・
                        シーケンス深度 (mapping sum)
  2. Aggregation       遺伝子ボディ (TSS→TES) メタジーン
  3. Sample correlation  サンプル間相関 (correlation_*.csv)
  4. PCA
  5. Differential expression (DESeq2)
     - ヒートマップ (同一 group のサンプルが隣り合うように列を並べ替える)
     - contrast ごとの M-A / Volcano (group×group 行列で選択)
  6. Gene expression   入力遺伝子の正規化カウント (box + beeswarm)
  7. Enrichment
     - GSEA (contrast × method を行列で選択)
     - ORA / cluster プロファイル

  すべての図は CSV から動的生成 (plotly / HTML)。各図には元データの Download
  ボタン、HTML テーブル (QC・heatmap・correlation) には Download PNG もあり。

バッチ表示 (任意):
  <out-dir>/sample_sheet.tsv に任意列 `batch` があると、レポート全体でバッチを
  見た目で区別する (列が無ければ従来どおりの表示)。
    - group の「色相」はそのまま。バッチは同系色の「濃淡」で表す。
    - PCA のマーカー: 1 番目のバッチ = 塗りつぶし丸 / 2 番目 = 白抜き丸
      (3 番目以降は菱形・四角)。凡例と hover にバッチ名が出る。
    - サンプル名の前にバッジ (● / ○ / ◆ ...) を付ける
      (Mapping QC / correlation / expression heatmap / サンプル選択)。
  例:
    fastq_prefix  genome  barcode  sample    group   batch
    posi          mm10    AGGATC   A_posi_1  A_posi  pic159
    WG5_23_nega   mm10    TCCTTC   A_posi_4  A_posi  pic155
  注: バッチ表示はあくまで可視化。DESeq2 の design には影響しない。

自己完結:
  プロジェクト内の全 csv/tsv を gzip+base64 で HTML に埋め込む。ダウンロード時に
  ブラウザ (DecompressionStream) で展開するため、fastq(demux) と html だけ渡せば
  すべての source データを html から取得できる (別途データファイル不要)。

RNA integrity (任意):
  RIN データセットのフォルダ直下に、名前 (フォルダ名かファイル名) が run 名で
  始まるもの (例: pic192_kimura_... 。直後は英数字以外) があれば、QC タブの
  先頭に「RNA integrity」を出す。無ければ出さない (エラーにもしない)。
    - TapeStation の export: <名前>_sampleTable.csv (RINe) /
      _compactPeakTable.csv (Lower Marker / 18S / 28S の位置) /
      _Electropherogram.csv (図の本体)。複数当たれば泳動ごとに並べる。
    - サンプル名は sampleTable の Sample Description に従う
      (sample_sheet とは突き合わせない)。
    - ladder は横軸 (nt) の較正だけに使い、描画しない。
    - 各波形の右に、その RINe を同じ色の数字で出す (RINe が空のサンプルは出さない)。
  pic all から呼ばれるときは PIC_RIN_DIR (か上の既定パス) を使う。

備考:
  pic all の最終ステップでも自動実行される。
