Usage:
  pic chipatlas --deftable <tsv> --umi <csv> --deg-list-dir <dir> \
    --genome <name> --out-dir <dir> [options]

Overview:
  Run ChIP-Atlas enrichment analysis per contrast.
  For each contrast:
    1) GOEA-like Enrichment analysis using DEGList
    2) GSEA-like PAGE using UMI raw-count table

Required options:
  --deftable <tsv>           Deftable TSV used for deseq2 input
  --umi <csv>                UMI_count_*.csv (raw count table)
  --deg-list-dir <dir>       DEGList directory from deseq2 output (DEG/DEGList)
  --genome <name>            Supported: hg38, mm10, rn6, dm6, ce11, sacCer3
  --out-dir <dir>            Output directory

Optional options:
  --antigen-class <text>     (default: TFs and others)
  --cell-class <text>        (default: All cell types)
  --threshold <n>            (default: 100)
  --distance-up <n>          (default: 5000)
  --distance-down <n>        (default: 5000)

Example:
  pic chipatlas \
    --deftable /path/to/deftable_mm10_xxx.tsv \
    --umi /path/to/UMI_count_mm10_xxx.csv \
    --deg-list-dir /path/to/deseq2_out/DEG/DEGList \
    --genome mm10 \
    --out-dir /path/to/chipatlas_out
