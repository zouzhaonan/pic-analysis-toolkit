Usage:
  pic deseq2 --deftable <path> --count-dir <dir> --genome <name> --out-dir <dir> [options]

Overview:
  Run DESeq2 statistical analysis and write result tables (CSV) only.
  Figures (correlation, PCA, MA, volcano, heatmap, DEG clusters) are drawn
  interactively by `pic report` from these tables; no static images are written.

Outputs (CSV; <project> = <run>_<genome>, taken from the deftable name
deftable_<run>_<genome>.tsv):
  stats_<project>.csv, normalizedCountTable_<project>.csv,
  UMI_count_<project>.csv, correlation_<project>.csv,
  PCA_<project>/PCA_RegLog_<project>.csv, PCA_<project>/PCA_Variance_<project>.csv,
  DEG_<project>/DEG_count_<project>.csv,
  DEG_<project>/DEG_normalizedCountTable_<project>.csv,
  DEG_<project>/DEGCluster_<project>/DEGCluster_*_<project>.csv,
  DEG_<project>/DEGList_<project>/<contrast>__<group>.txt

Prerequisite:
  Target genome must be registered with:
  pic manage-biomart --register

Required options:
  --deftable <path>     DESeq2 sample sheet
                        Example:
                        - - - - - - - - - - - - - - - - - - - - -
                          count_prefix  barcode  sample   group
                          brain         AGGATC   brain_1  brain
                          brain         TCGAAG   brain_2  brain
                          ovary         TCCTTC   ovary_1  ovary
                          ovary         TGTCTG   ovary_2  ovary
                        - - - - - - - - - - - - - - - - - - - - -
  --count-dir <dir>     Directory containing *.txt.gz files
  --genome <name>       Genome name (e.g. mm10, hg38)
  --out-dir <dir>       Output directory

Optional options:
  --fdr <value>         FDR threshold for DEG calling (default: 0.1)
  --threads <n>         Run rlog alongside the DESeq2 fit and extract the
                        contrasts in parallel (default: 1). Results are the
                        same as with 1.

Example:
  pic deseq2 \
    --deftable /path/to/out/summary/deftable_test_mm10.tsv \
    --count-dir /path/to/out/counts \
    --genome mm10 \
    --out-dir /path/to/out
