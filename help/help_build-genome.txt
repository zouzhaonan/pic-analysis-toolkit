Usage:
  pic build-genome --genome <name> --fasta <path> --gtf <path> [options]

Overview:
  Prepare and register genome references including HISAT2 index and GTF.

Required options:
  --genome <name>          Genome name (e.g. mm10, hg38)
  --fasta <path>           Reference FASTA
  --gtf <path>             Reference GTF

Optional options:
  --fasta-source <text>    FASTA source note (default: unspecified)
  --gtf-source <text>      GTF source note (default: unspecified)
  --threads <int>          Threads for HISAT2 index build (default: 8)

Output locations:
  - HISAT2 index:   <PIC_LIB>/hisat2_index/<genome>/genome.*.ht2*
  - GTF:            <PIC_LIB>/gtf/<genome>.gtf
  - chrom sizes:    <PIC_LIB>/chrom_size/<genome>.chrom.sizes
  - registry TSV:   <PIC_LIB>register/genome_map.tsv (genome name + source notes)

  * PIC_LIB defaults to $HOME/local/lib/pic when not set

Example:
  pic build-genome \
    --genome mm10 \
    --fasta /path/mm10.fa \
    --gtf /path/mm10.gtf \
    --fasta-source "url.com/mm10.fasta.gz" \
    --gtf-source "url.com/mm10.gtf.gz"
