# pic 解析パイプライン実行例

マウス `Brain` vs `Ovary`（*n* = 2）のテストデータで、`pic` の基本ワークフローを確認します。

## 1. データセットを準備

```bash
mkdir -p "$HOME/tmp"
cd "$HOME/tmp"
curl -L "https://chip-atlas.dbcls.jp/data/share/pic_test.tar.gz" | tar zx

wd="$HOME/tmp/pic_test"
```

## 2. マッピングを実行

### 2-1. conda 環境を有効化

```bash
shell_name="$(basename "${SHELL:-zsh}")"
eval "$("$(command -v conda)" "shell.${shell_name}" hook)"
conda activate pic
```

### 2-2. mapping を実行

```bash
pic mapping \
  --sample-sheet "$wd/sample_sheet__test.txt" \
  --raw-fastq-dir "$wd/fastq" \
  --out-dir "$wd" \
  --run-name test
```

完了後に `mapping_sum` を確認します。

```bash
cat "$wd/mapping_sum__test.tsv"
```

`brain` と `ovary` が各2サンプル分表示されれば正常です。

## 3. DESeq2 解析

`deftable` は `pic mapping` 完了時に自動生成されます。

```bash
pic deseq2 \
  --deftable "$wd/deftable_mm10_test.tsv" \
  --count-dir "$wd/counts" \
  --genome mm10 \
  --out-dir "$wd/deseq2"
```

完了後に `stats` を確認します。

```bash
cat "$wd/deseq2/stats_mm10_test.csv"
```

## 4. ORA/GSEA 解析

```bash
pic enrich \
  --stats "$wd/deseq2/stats_mm10_test.csv" \
  --genome mm10 \
  --out-dir "$wd/enrich" \
  --deg-clusters "$wd/deseq2/DEG/DEGCluster/DEGCluster_gene_for_ora_mm10_test.csv"
```

`$wd/enrich` 配下に `plots/` と `csv/` が作成され、実際に結果が出力されれば正常です。

## 5. ChIP-Atlas 解析

```bash
pic chipatlas \
  --deftable "$wd/deftable_mm10_test.tsv" \
  --umi "$wd/deseq2/UMI_count_mm10_test.csv" \
  --deg-list-dir "$wd/deseq2/DEG/DEGList" \
  --genome mm10 \
  --out-dir "$wd/chipatlas"
```

計算は ChIP-Atlas 側で実行されます。完了すると結果が `out-dir/results` 配下に保存されます。

## 6. plot-expression

対象遺伝子ごとに、各群の normalized count をプロットします。

まず、プロット対象の遺伝子リストを作成します。

```bash
cat > "$wd/genes.txt" <<'EOF'
Map2
Gfap
Ddx4
Kit
EOF
```

次に、`deseq2` 出力の normalized count table を使って発現プロットを作成します。

```bash
pic plot-expression \
  --count "$wd/deseq2/normalizedCountTable_mm10_test.csv" \
  --deftable "$wd/deftable_mm10_test.tsv" \
  --gene-list "$wd/genes.txt" \
  --out "$wd/deseq2/plot_expression_test.pdf"
```

`$wd/deseq2/plot_expression_test.pdf` が生成されれば正常です。

## 7. 後片付け

### 7-1. conda 環境を終了

```bash
conda deactivate
```

### 7-2. テストデータと解析結果を削除（必要な場合のみ）

```bash
rm -rf "$wd"
```
