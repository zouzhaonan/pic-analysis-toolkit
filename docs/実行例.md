# pic 解析パイプライン実行例

マウス `Brain` vs `Ovary`（*n* = 2）のテストデータで、`pic` の基本ワークフローを確認します。
`pic all` 1 本で mapping → DESeq2 → ORA/GSEA → HTML レポートまで実行し、最後にレポートをブラウザで開きます。

## 1. データセットを準備

```bash
mkdir -p "$HOME/tmp"
cd "$HOME/tmp"
curl -L "https://chip-atlas.dbcls.jp/data/share/pic_test.tar.gz" | tar zx

wd="$HOME/tmp/pic_test"
```

## 2. conda 環境を有効化

```bash
shell_name="$(basename "${SHELL:-zsh}")"
eval "$("$(command -v conda)" "shell.${shell_name}" hook)"
conda activate pic
```

`conda activate pic` を忘れると、`pic` コマンドが見つからないか、Linux では別のプログラム（groff の `pic`）が動きます。

## 3. `pic all` で一括実行

```bash
pic all \
  --sample-sheet "$wd/sample_sheet__test.txt" \
  --raw-fastq-dir "$wd/fastq" \
  --out-dir "$wd" \
  --run-name test
```

最後に `pic all: 完了しました` と表示されれば終了です。

`mapping_sum` で、`brain` と `ovary` が各 2 サンプル分あることを確認します。

```bash
cat "$wd/summary/mapping_sum__test.tsv"
```

## 4. レポートを開く

```bash
open "$wd/report_test_mm10.html"
```

レポートは 1 つの HTML にすべてのデータを埋め込んであるので、このファイルだけを人に渡しても見られます。
主な出力は次のとおりです（`<run>_<genome>` = `test_mm10`）。

| 場所 | 中身 |
| --- | --- |
| `$wd/summary/` | `mapping_sum__test.tsv`、`deftable_test_mm10.tsv` など |
| `$wd/deseq2/` | `stats_test_mm10.csv`、`normalizedCountTable_test_mm10.csv`、`DEG_test_mm10/` など |
| `$wd/enrich/` | `GSEA/<method>/*.csv`、`ORA/<method>/*.csv` |
| `$wd/report_test_mm10.html` | HTML レポート |

## 5. 応用: サブコマンドを個別に実行

FDR や enrichment の method を変えたいとき、ChIP-Atlas 解析や遺伝子ごとの図が欲しいときは、`pic all` の結果を使ってサブコマンドを個別に実行します。

### 5-1. DESeq2（FDR を変える例）

```bash
pic deseq2 \
  --deftable "$wd/summary/deftable_test_mm10.tsv" \
  --count-dir "$wd/counts" \
  --genome mm10 \
  --fdr 0.05 \
  --out-dir "$wd/custom/deseq2"
```

### 5-2. ORA/GSEA（method を選ぶ例）

```bash
pic enrich \
  --stats "$wd/custom/deseq2/stats_test_mm10.csv" \
  --genome mm10 \
  --methods GO_BP,KEGG \
  --out-dir "$wd/custom/enrich" \
  --deg-clusters "$wd/custom/deseq2/DEG_test_mm10/DEGCluster_test_mm10/DEGCluster_gene_for_ora_test_mm10.csv"
```

`$wd/custom/enrich/` 配下に `GSEA/<method>/*.csv` と `ORA/<method>/*.csv` が作成されれば正常です。

### 5-3. ChIP-Atlas 解析

```bash
pic chipatlas \
  --deftable "$wd/summary/deftable_test_mm10.tsv" \
  --umi "$wd/deseq2/UMI_count_test_mm10.csv" \
  --deg-list-dir "$wd/deseq2/DEG_test_mm10/DEGList_test_mm10" \
  --genome mm10 \
  --out-dir "$wd/chipatlas"
```

計算は ChIP-Atlas 側で実行されます。完了すると結果が `<out-dir>/result/` 配下に保存されます。

### 5-4. plot-expression

対象遺伝子ごとに、各群の normalized count をプロットします。

```bash
cat > "$wd/genes.txt" <<'EOF'
Map2
Gfap
Ddx4
Kit
EOF

pic plot-expression \
  --count "$wd/deseq2/normalizedCountTable_test_mm10.csv" \
  --deftable "$wd/summary/deftable_test_mm10.tsv" \
  --gene-list "$wd/genes.txt" \
  --out "$wd/plot_expression_test.pdf"
```

`Warning` が出ることがありますが、`$wd/plot_expression_test.pdf` が正常にできていれば問題ありません。

## 6. 後片付け

### 6-1. conda 環境を終了

```bash
conda deactivate
```

### 6-2. テストデータと解析結果を削除（必要な場合のみ）

```bash
rm -rf "$wd"
```
