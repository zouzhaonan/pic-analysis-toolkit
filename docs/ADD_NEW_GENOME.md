# Adding a New Genome

This document explains how to add a new genome to `pic`, using rat `rn7` as an example.

## 1. Pre-check

```bash
conda activate pic
pic --help
```

## 2. Prepare rn7 FASTA/GTF

In this example, download and extract FASTA/GTF files from Ensembl.

```bash
mkdir -p "$HOME/tmp/rn7_ref"
cd "$HOME/tmp/rn7_ref"

curl -L -o Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz \
  "https://ftp.ensembl.org/pub/release-115/fasta/rattus_norvegicus/dna/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz"

curl -L -o Rattus_norvegicus.mRatBN7.2.115.gtf.gz \
  "https://ftp.ensembl.org/pub/release-115/gtf/rattus_norvegicus/Rattus_norvegicus.mRatBN7.2.115.gtf.gz"

gunzip -f Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz
gunzip -f Rattus_norvegicus.mRatBN7.2.115.gtf.gz
```

If `curl` stalls or downloaded files are unexpectedly small, your network may be unstable. Re-run the commands above.

## 3. Build HISAT2 index

Compressed `.gz` FASTA/GTF files are not supported as direct input, so confirm they are extracted first.
HISAT2 index build may take tens of minutes.
Also, this step can fail when disk space is low; keep at least several tens of GB free.

```bash
pic build-genome \
  --genome rn7 \
  --fasta "$HOME/tmp/rn7_ref/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa" \
  --gtf "$HOME/tmp/rn7_ref/Rattus_norvegicus.mRatBN7.2.115.gtf" \
  --fasta-source "https://ftp.ensembl.org/pub/release-115/fasta/rattus_norvegicus/dna/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz" \
  --gtf-source "https://ftp.ensembl.org/pub/release-115/gtf/rattus_norvegicus/Rattus_norvegicus.mRatBN7.2.115.gtf.gz" \
  --threads 8
```

## 4. Retrieve and register the rn7 dataset from Ensembl biomart

The goal is to build a mapping table between Ensembl IDs and gene symbols (+ chr + biotype + human_ortholog).

### 4-1. Find the dataset name for rn7 (rat)

```bash
pic manage-biomart --list-datasets
```

Search with a keyword such as `Rat`, then use `rnorvegicus_gene_ensembl`.

In many cases dataset names can be guessed from scientific names, but it is recommended to verify with `pic manage-biomart --list-datasets`.

### 4-2. Download and register the dataset into `pic`

```bash
pic manage-biomart --register \
  --genome rn7 \
  --dataset rnorvegicus_gene_ensembl
```

#### Tips

- `No biomart datasets were returned`
  - This is often a temporary Ensembl/BioMart-side issue. Wait and retry.

### 4-3. Verify biomart registration

```bash
cat "$HOME/local/lib/pic/register/biomart_lookup.tsv"
ls -la "$HOME/local/lib/pic/biomart" | grep rnorvegicus_gene_ensembl
```

Checkpoints:
- `biomart_lookup.tsv` has a row for `rn7` and `rnorvegicus_gene_ensembl`
- `biomart/rnorvegicus_gene_ensembl.tsv` exists

#### Tips

- Gene counts generated by `pic mapping` use gene IDs written in the GTF.
  For some special species (especially when GTF is provided directly by collaborators), IDs may not be Ensembl IDs. In that case, downloading from biomart may not produce a usable ID mapping.

- In such cases, place a manually created TSV under `$HOME/local/lib/pic/biomart` and add the required metadata row to `$HOME/local/lib/pic/register/biomart_lookup.tsv`.

  - For example, if your count table already contains gene symbols instead of gene IDs:
    - Put gene symbols in both `ens_gene` and `ext_gene`.
    - `biotype` and `chr` can be any placeholder value (for example `NA`).
    - `human_ortholog` is used by `enrich`; if strict ortholog mapping is unavailable, uppercase gene symbols can be used as a practical fallback.

  ##### Example:

  | ens_gene   | ext_gene   | biotype         | chr | human_ortholog |
  |------------|------------|-----------------|-----|----------------|
  | U6         | U6         | snRNA           | 1   |                |
  | U4         | U4         | snRNA           | 1   |                |
  | U6         | U6         | snRNA           | 1   |                |
  | SLITRK6    | SLITRK6    | protein_coding  | 1   | SLITRK6        |
  | U6         | U6         | snRNA           | 1   |                |
  | cja-mir-31 | cja-mir-31 | miRNA           | 1   | MIR31          |
  | PCID2      | PCID2      | protein_coding  | 1   | PCID2          |
  | SLITRK5    | SLITRK5    | protein_coding  | 1   | SLITRK5        |
  | U6         | U6         | snRNA           | 1   |                |

## 5. Prepare enrichment libraries

```bash
pic enrich --prepare-libs --genome rn7
```
