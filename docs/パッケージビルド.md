# PIC パッケージ作成手順

以下では `<version>` を今回リリースするバージョン (例 `1.3.0`) に読み替えること。

## 1. 事前準備

- macOS もしくは Linux
- Conda
- conda-build
- GitHub Release を作る場合は `gh` CLI (`gh auth login` 済み)

```bash
conda install -n base -c conda-forge conda-build
```

## 2. バージョンを更新する

`VERSION` と recipe の両方を同じ値にする。`VERSION` は `pic help` の表示に、
recipe はパッケージ名に使われるため、片方だけだと食い違う。

```bash
repo=/Users/zou/pic-analysis-toolkit

echo "<version>" > "$repo/VERSION"
# src/recipe/meta.yaml の {% set version = "..." %} も同じ値に変更する
```

## 3. 生成物を削除する

ビルド用の croot だけを消す。

```bash
build_dir=/Users/zou/local/conda-bld-pic

rm -rf "$build_dir"
```

> **`pic` 環境は消さないこと。**
> 動作確認は手順 6 で別名の環境を作って行う。稼働中の解析環境を壊す必要はない。
>
> **`src/pic-channel` も消さないこと。**
> チャンネルは累積で運用しており、過去バージョンの `.conda` を残したまま
> 新しいものを追加する (手順 5)。消すと過去バージョンでの再現ができなくなる。

## 4. パッケージをビルドする

```bash
recipe_dir=/Users/zou/pic-analysis-toolkit/src/recipe

conda config --set solver libmamba
conda config --set channel_priority strict
conda clean -i -y

conda build "$recipe_dir" \
  --croot "$build_dir" \
  --override-channels \
  -c conda-forge -c bioconda
```

`TEST END: .../pic-<version>-0.conda` まで出れば成功。所要時間は数分程度。

## 5. `pic-channel` に追加する

既存の `.conda` は残したまま、新しいものをコピーして再インデックスする。

```bash
channel_dir=/Users/zou/pic-analysis-toolkit/src/pic-channel

cp "$build_dir/noarch/pic-<version>-0.conda" "$channel_dir/noarch/"
conda index "$channel_dir"

cd /Users/zou/pic-analysis-toolkit/src
rm -f pic-channel.zip
zip -r pic-channel.zip pic-channel
```

`repodata.json` に全バージョンが、`current_repodata.json` に最新のみが
載っていることを確認する。

```bash
python3 -c "
import json
d = json.load(open('$channel_dir/noarch/repodata.json'))
print('repodata:', sorted(v['version'] for v in d['packages.conda'].values()))
c = json.load(open('$channel_dir/noarch/current_repodata.json'))
print('current :', sorted(v['version'] for v in c['packages.conda'].values()))"
```

## 6. インストールを確認する

**別名の環境**を作ってチャンネルから入るかを確かめる。稼働中の `pic` 環境には触れない。

```bash
conda create -y -n pic-test -c "$channel_dir" -c conda-forge -c bioconda \
  --override-channels pic=<version>

conda run -n pic-test pic help | head -1   # pic <version> と出れば OK
```

確認が済んだら片付ける。

```bash
conda env remove -n pic-test -y
```

## 7. コミットする

```bash
cd /Users/zou/pic-analysis-toolkit
git add -A VERSION src/
git commit -m "release: pic <version> パッケージを pic-channel に追加"
git push origin master
```

## 8. タグと Release を作る

タグはマージコミットに対して打つ。

```bash
git tag -a v<version> -m "PIC v<version>

<変更点の要約>"
git push origin v<version>

gh release create v<version> src/pic-channel.zip \
  --title "pic <version>" \
  --notes-file <リリースノート.md>
```

GitHub の Web UI から作る場合は Releases → Draft a new release で、
Tag に `v<version>`、Title に `pic <version>` を入れ、`pic-channel.zip` を
添付して Publish する。
