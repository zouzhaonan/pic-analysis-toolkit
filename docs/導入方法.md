# pic 解析用ツールキット導入ガイド

Apple Silicon Mac でのみ動作確認しています。
**⚠️ Intel Mac は未検証です。Windows では動きません。⚠️**

このガイドを最後まで実行すると、ツールのインストールと hg38 / mm10 のリファレンス準備が完了します。
**⚠️ 全工程で数時間かかる場合があります。ネットが安定した環境で、時間に余裕があるときに実行してください。⚠️**

## 1. 事前準備

### 1-1. Miniconda を入れる（未導入の人だけ）

すでに `conda` が使える場合は飛ばしてください。

- インストーラを[ダウンロード](https://www.anaconda.com/download/success)
- 通常のアプリと同様にインストールしてください。

### 1-2. ターミナルで `conda` が使えるか確認

```bash
conda --version
```

---

## 2. `pic-channel` をダウンロード

配布された `pic-channel` フォルダを、任意の場所に置いてください。
例: `~/Downloads/pic-channel`

**※ インストールした後に削除しても大丈夫です。**

---

## 3. インストール

以下の手順を、順番にターミナルへコピーして実行してください。

### 3-1. 念のため、既存の `pic` 環境を消す

途中でエラーのような表示が出ても問題ありません。

```bash
conda deactivate || true
conda env remove -n pic -y || true
```

### 3-2. `pic-channel` のパスを取得

```bash
cd ~/Downloads/pic-channel
channel_dir="$(pwd)"
```

### 3-3. インストール実行

数十分、同じところで止まっているように見えることがあります。
正常な動作なので、そのまま待ってください。

```bash
conda config --set channel_priority strict

conda create -n pic -y \
  --override-channels \
  -c "file://$channel_dir" \
  -c conda-forge -c bioconda \
  pic
```

---

## 4. 起動確認

### 4-1. 環境を有効化

```bash
conda activate pic
```

### 4-2. ヘルプ表示

```bash
pic
```

ヘルプが表示されれば導入完了です。

## 5. ヒト（hg38）とマウス（mm10）のリファレンスを整備

別の生物種（ゲノム）の準備方法は、操作方法ドキュメントを参照してください。
ここでは、まず解析を実行できる状態にするため、hg38 と mm10 を配置します。

```bash
mkdir -p $HOME/local/lib
cd $HOME/local/lib
curl https://chip-atlas.dbcls.jp/data/share/pic.tar.gz| tar zx

cd
```
