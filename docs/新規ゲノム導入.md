# 新規ゲノム導入手順

ラット `rn7` を例として、`pic` に新規ゲノムを導入する手順を説明します。

## 1. 事前確認

```bash
conda activate pic
pic --help
```

## 2. rn7 の FASTA/GTF を用意

ここでは例として、Ensembl の FASTA/GTF をダウンロードして解凍します。

```bash
mkdir -p "$HOME/tmp/rn7_ref"
cd "$HOME/tmp/rn7_ref"

curl -L -o Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz \
  "https://ftp.ensembl.org/pub/release-115/fasta/rattus_norvegicus/dna/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz"

curl -L -o Rattus_norvegicus.mRatBN7.2.115.gtf.gz \
  "https://ftp.ensembl.org/pub/release-115/gtf/rattus_norvegicus/Rattus_norvegicus.mRatBN7.2.115.gtf.gz"

gunzip -f Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz
gunzip -f Rattus_norvegicus.mRatBN7.2.115.gtf.gz
```

`curl` が途中で止まる、またはダウンロードされたファイルサイズが異常に小さい場合は、ネットワーク不安定の可能性があります。上記コマンドを再実行してください。

## 3. HISAT2 index を作成

圧縮形式（`.gz`）の FASTA/GTF は非対応のため、事前に解凍されていることを確認してください。
HISAT2 index の作成には数十分かかることがあります。
また、ディスク不足で失敗することがあるため、数十 GB 以上の空き容量を確保してください。

```bash
pic build-genome \
  --genome rn7 \
  --fasta "$HOME/tmp/rn7_ref/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa" \
  --gtf "$HOME/tmp/rn7_ref/Rattus_norvegicus.mRatBN7.2.115.gtf" \
  --fasta-source "https://ftp.ensembl.org/pub/release-115/fasta/rattus_norvegicus/dna/Rattus_norvegicus.mRatBN7.2.dna.primary_assembly.fa.gz" \
  --gtf-source "https://ftp.ensembl.org/pub/release-115/gtf/rattus_norvegicus/Rattus_norvegicus.mRatBN7.2.115.gtf.gz" \
  --threads 8
```

## 4. Ensembl biomart から rn7 の該当データセットを取得

目的は、Ensembl ID と gene symbol の対応表（+ chr + biotype + human_ortholog）を作成することです。

### 4-1. rn7（rat）に対応するデータセット名を確認

```bash
pic manage-biomart --list-datasets
```

`Rat` などでキーワード検索していくと、 `rnorvegicus_gene_ensembl` が出てきますので、これを使用します。

このように、多くのデータセット名は学名から推測できますが、念のため `pic manage-biomart --list-datasets` で一覧を確認することを推奨します。

### 4-2. 該当データセットをダウンロードして `pic` に登録

```bash
pic manage-biomart --register \
  --genome rn7 \
  --dataset rnorvegicus_gene_ensembl
```

#### Tips

- `No biomart datasets were returned`
  - Ensembl/BioMart 側の一時障害の可能性があります。時間を置いて再実行してください。

### 4-3. biomart 登録を確認

```bash
cat "$HOME/local/lib/pic/register/biomart_lookup.tsv"
ls -la "$HOME/local/lib/pic/biomart" | grep rnorvegicus_gene_ensembl
```

確認ポイント:
- `biomart_lookup.tsv` に `rn7` と `rnorvegicus_gene_ensembl` の行がある
- `biomart/rnorvegicus_gene_ensembl.tsv` が存在する

#### Tips:
- `pic mapping` が出力する遺伝子カウントには、GTF に記載された gene ID が使われます。特殊な生物種（特に共同研究先から直接 GTF を受け取るケース）では、Ensembl ID ではない場合があります。その場合、biomart からデータセットを取得しても ID 変換がうまくいきません。

- その際は、`$HOME/local/lib/pic/biomart` 配下に手動作成した TSV を置き、`$HOME/local/lib/pic/register/biomart_lookup.tsv` に必要情報を追記してください。

  - 例えば、count table で gene ID ではなく gene symbol がそのまま出る場合
    - `ens_gene` と `ext_gene` に gene symbol を入力します。
    - `biotype` と `chr` は任意文字列（`NA` など）で構いません。
    - `human_ortholog` は `enrich` で使用されますが、厳密な ortholog が取れない場合は大文字遺伝子名で代用する運用も可能です。

  ##### Example:

    | ens_gene   | ext_gene   | biotype         | chr | human_ortholog |
    |------------|------------|-----------------|-----|----------------|
    | U6         | U6         | snRNA           | 1   |                |
    | U4         | U4         | snRNA           | 1   |                |
    | U6         | U6         | snRNA           | 1   |                |
    | SLITRK6    | SLITRK6    | protein_coding  | 1   | SLITRK6        |
    | U6         | U6         | snRNA           | 1   |                |
    | cja-mir-31 | cja-mir-31 | miRNA           | 1   | MIR31          |
    | PCID2      | PCID2      | protein_coding  | 1   | PCID2          |
    | SLITRK5    | SLITRK5    | protein_coding  | 1   | SLITRK5        |
    | U6         | U6         | snRNA           | 1   |                |

## 5. enrich 用ライブラリを準備

```bash
pic enrich --prepare-libs --genome rn7
```
